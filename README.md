# Lasik for Ghostty

Install:

1. Copy this file to `~/.config/ghostty/themes/lasik` (the file has no extension: its name is the theme's name)

2. Add this line to `~/.config/ghostty/config`:

```bash
theme = lasik
```

3. Reload the config: `Ctrl+Shift+,` (macOS: `Cmd+Shift+,`)

Check: `ghostty +list-themes` shows "lasik" in its list.
